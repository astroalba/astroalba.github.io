# astroalba.github.io

Personal website of Alba Covelo Paz, served by GitHub Pages at https://astroalba.github.io.

Plain HTML/CSS, no build step. Edit the page you want and push:

| Page | English | Français | Español |
|------|---------|----------|---------|
| Home | `index.html` | `fr/accueil/index.html` | `es/inicio/index.html` |
| CV   | `cv_en/index.html` | `fr/cv_fr/index.html` | `es/cv_es/index.html` |

Styles are in `style.css`, images in `images/`.

Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
